- 9 unsafe blocks, each with SAFETY comment, grouped one per method
- set_affinity: SetThreadGroupAffinity + GetThreadGroupAffinity read-back

- set_priority: SetPriorityClass + GetPriorityClass read-back, HIGH_PRIORITY_CLASS only

  working set raised first (else ERROR_WORKING_SET_QUOTA 1453),
  returns ALIGNED length, all FAIL CLOSED

  KAFFINITY stays one usize, PlanError::MultiGroupSpan for cross-group
